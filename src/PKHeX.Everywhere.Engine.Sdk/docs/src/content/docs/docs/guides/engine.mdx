`@pkhex-everywhere/engine` works in any framework, or none. `createEngine()` returns a client whose namespaces mirror the save: `game`, `party`, `box`, `pokemon`, `trainer`, `inventory`, `events`, `species`, `encounters`, `catalog` and `plugins`.

## Boot status

In a browser, `createEngine()` starts downloading the runtime right away. Pass `{ lazy: true }` to wait for the first call instead. On a server it does nothing until called.

`engine.status` is `{ state, loaded, total, error? }`, where `state` is `idle`, `booting`, `ready` or `failed`, and `loaded` and `total` count downloaded files. `engine.onStatusChange(listener)` returns a function that stops listening:

```ts
engine.onStatusChange(({ state, loaded, total }) => {
  if (state === 'booting') progress.value = total ? loaded / total : 0
})
```

`await engine.ready` resolves once the runtime is up. If the runtime fails to load, `state` becomes `failed` and every call rejects with the error.

## Loading and exporting

```ts
await engine.game.load(file)
const game = await engine.game.get()

const { bytes, fileName } = await engine.game.export()
```

Binary inputs take a `Uint8Array`, `ArrayBuffer`, `Blob` or `File`, and binary outputs come back as `Uint8Array`. `game.load` takes the file name from a `File` when you leave it out. `game.loadBlank(version)` starts an empty save, and `game.close()` unloads it.

## Queries and commands

Every call returns a promise. Calls are either **queries**, which read (`party.get`, `trainer.get`, `pokemon.details`), or **commands**, which change the save (`trainer.setMoney`, `inventory.setItem`, `pokemon.setLevel`). The exported `queries` and `commands` arrays list them, and `QueryName` and `CommandName` type them.

Hover a method in your editor to see whether it needs a loaded save or an open draft.

## Handles

Calls that act on one Pokémon take a `PokemonHandle`, which gives its source and slot.

```ts
const lead = { source: 'party', slot: 0 } as const
const boxed = { source: 'box', box: 2, slot: 14 } as const

await engine.pokemon.setLevel(lead, 100)
```

## Drafts

Edits that span several fields go through a draft. The engine holds a copy of the Pokémon, you change it, then you commit it. There is at most one draft at a time, addressed with `draftHandle`.

```ts
import { draftHandle } from '@pkhex-everywhere/engine'

await engine.pokemon.edit(lead)
await engine.pokemon.update(draftHandle, { nickname: 'Sparky' })
await engine.pokemon.commit()
```

- `pokemon.edit(at)` opens a copy of a saved slot and replaces any open draft.
- `pokemon.clone(at)` opens a draft with no slot. `commit` fails on it with `no-slot`; use `pokemon.addToBox` instead.
- Loading or closing a save drops the draft.

## Trading between saves

`trade.open` loads a partner save next to the loaded one. Pokémon move between them the way the games move them: a link trade between saves of the same format, the Time Capsule between Generation 1 and 2, Pal Park from Generation 3 to 4 and Poké Transfer from Generation 4 to 5.

```ts
const trade = await engine.trade.open(partnerFile)
trade.routes // { send: 'palPark', receive: null }

const offer = { send: [boxed], receive: [] }
const { offers, refused } = await engine.trade.preview(offer)

const { save, partner, arrived } = await engine.trade.commit(offer)
await engine.trade.close()
```

- `send` handles point into the loaded save, and `receive` handles into the partner. `trade.partnerBoxes()` lists the partner's Pokémon.
- Each offer shows the Pokémon as it is and as it arrives, the fields the move changes and why, and its legality in the destination game.
- `commit` fails with `trade-refused`, changing nothing, while `preview` refuses any Pokémon in the offer. It returns both saves' bytes.

## Reacting to changes

`engine.subscribe(topics, callback)` calls back when a command changes something under those topics. Topics are `game`, `party`, `box`, `inventory`, `events`, `trainer`, `draft`, `plugins`, `trade`, or `*` for everything:

```ts
const stop = engine.subscribe(['party'], async () => {
  render(await engine.party.get())
})
```

For typed events such as `PokemonSaved` or `GameExported`, use `engine.onEvent(listener)`.

## Errors

Commands that fail reject with an `EngineError`. Its `code` is one of `errorCodes`, such as `no-save`, `box-full` or `invalid-save`:

```ts
import { EngineError } from '@pkhex-everywhere/engine'

try {
  await engine.game.load(file)
} catch (error) {
  if (error instanceof EngineError && error.code === 'invalid-save') alert('Not a save file')
  else throw error
}
```

A save that might be in a format PKHeX doesn't know, such as a ROM hack, fails with `format-choice-required`. Its `candidates` list those formats. Load the save again with the chosen `formatId`, or with `pkhex` to load it the way PKHeX detects it:

```ts
if (error instanceof EngineError && error.code === 'format-choice-required') {
  const formatId = await askUser(error.candidates)
  await engine.game.load(file, undefined, formatId)
}
```

## Where the runtime loads from

By default the browser loads `_framework/dotnet.js` from jsDelivr, pinned to the installed version of the package.

### Vite

To serve the runtime from your own site, add the plugin:

```ts title="vite.config.ts"
import { defineConfig } from 'vite'
import pkhexEngine from '@pkhex-everywhere/engine/vite'

export default defineConfig({
  plugins: [pkhexEngine()],
})
```

In dev it serves `/_framework`, and at build it copies `_framework` into the output. `createEngine()` then loads `/_framework/dotnet.js` from your site and makes no request to jsDelivr. Pass `frameworkDir` to serve another folder:

```ts
pkhexEngine({ frameworkDir: '/path/to/_framework' })
```

### Other bundlers

Copy `node_modules/@pkhex-everywhere/engine/_framework` to your site and pass the URL of `dotnet.js`:

```ts
import { createEngine, wasmHost } from '@pkhex-everywhere/engine'

const engine = createEngine({ host: wasmHost({ dotnetUrl: '/_framework/dotnet.js' }) })
```

`dotnetUrl` also works with the Vite plugin, for example to load the runtime from your own CDN.

A page has one runtime. Every `wasmHost()` call returns it, so engines on the same page share it. The first call picks the URL, and a later call with a different `dotnetUrl` logs a warning.
