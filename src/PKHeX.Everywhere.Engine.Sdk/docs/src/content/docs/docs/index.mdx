The SDK runs [PKHeX.Core](https://github.com/kwsch/PKHeX) on .NET WebAssembly and gives you a typed TypeScript client for it. Load a Pokémon save file, read and edit it, and export it, all in the browser.

There are three packages:

| Package | What it is |
| --- | --- |
| `@pkhex-everywhere/engine` | The runtime and the client. Works with any framework, or none. |
| `@pkhex-everywhere/react` | Provider and Suspense hooks over the engine. |
| `@pkhex-everywhere/plugin-sdk` | Types for page modules of PKHeX.Everywhere plug-ins. |
